Toddler Word Breaker


A simple educational game that helps toddlers practice breaking words into syllables or sounds to improve pronunciation and general foundations for reading.

How It Works 

The game shows a word. The child identifies how many syllables or sounds the word has. Positive reinforcement for correct answers. If wrong, just reset and try again!


How to Run 

Clone the folder, or download it. 

Install dependencies: pip install -r requirements.txt run: python toddler_word_split_game.py or double-click run_game.bat 

Requires Python 3.x 

Requires pyttsx3 for sound and tkinter/powershell on windows. 

Current audio path is windows-friendly, additional changes may be needed for non-windows users.
